If a test fails

* [ ]	Save the exact error, timestamp, configuration, and run ID.
* [ ]	Keep the failed result in the spreadsheet.
* [ ]	Stop increasing the workload.
* [ ]	Record the next investigation needed before continuing.

Remember: arrival counts measure when Java observed changes. RDI backlog comes from RDI metrics, and timeouts are unconfirmed outcomes—not successful latency measurements.
